# AGENTS.md

Guidance for coding agents (Claude Code, Codex, Gemini CLI, opencode, Cursor, Copilot, ...). Read this
first. It is deliberately short; the detail lives in the documents it links to.

## What this is

LANoMAT v2 is a modular LAN-party management tool: events, registration with QR tickets, seating,
tournaments with brackets, schedule, catering, voting, LFG, infoscreens, Discord, voice (TeamSpeak,
LiveKit), game servers. It is a **Laravel monolith**: PHP 8.4, Laravel 13, Filament v5 (admin panel at
`/admin`), Inertia v2 + Vue 3 + Tailwind v4 + shadcn-vue (participant app), Reverb (websockets),
PostgreSQL 16, Redis, Docker Compose, Pest. The code is MIT licensed and public.

## Develop

```bash
docker compose up -d           # Postgres (host port 5434) + Redis (6380): deliberate non-default ports
composer install && npm install
cp .env.example .env && php artisan key:generate
php artisan migrate && php artisan db:seed --class=ScreenshotSeeder
composer run dev               # app + queue + Vite; login page has demo buttons under APP_ENV=local
```

Before you call work done, all of these must be green:

```bash
composer check                 # Pint (--test), PHPStan level 8, Pest
npm run types:check && npm run lint:check && npm run format:check && npm run build
```

Run one test with `./vendor/bin/pest --filter=Name`. Do not run Pest with `--parallel` (shared database).
Never call real external APIs in tests: Discord, Mumble, TeamSpeak and Pelican sit behind contracts with
fake implementations.

## Architecture rules

- **Modular monolith:** `app/Modules/<Name>/{Models,Actions,Policies,Filament,Jobs,Events,Contracts}`;
  tests mirror it in `tests/{Feature,Unit}/<Name>/`. Modules talk through Laravel events and explicit
  contracts, never through each other's tables.
- **Modules are toggles** (`config/modules.php`, `MODULES_PROFILE=core|full`, `MODULE_<KEY>=true|false`).
  A new module needs an enum case, gating in routes, Filament, scheduler and policies, and a `requires()`
  entry if it needs another one. The architecture tests enforce this.
- **`Event` is the aggregate root** for everything organisational. Users, teams and games are cross-event.
- **Every authorization goes through a Policy.** Never trust a client-supplied user id.
- **One class per use case** (`app/Modules/*/Actions`); controllers and Filament resources stay thin.
- **The bracket engine is pure domain code** (`app/Modules/Tournaments/Domain/`): no IO.
- Uploads go to Laravel Storage, never base64 into the database.
- A new route needs an entry in `tests/Feature/Security/RouteAuthorizationMatrixTest.php`.

## Conventions

- Code, comments, commits and docs in **English**. UI copy is **German** (`lang/de/`).
- Conventional Commits (`feat(scope): ...`). Tests first where behaviour is testable.
- PHP: Pint (Laravel preset), PHPStan level 8, enums instead of magic strings.
- Vue: `<script setup lang="ts">`, no `<style>` blocks, Tailwind and shadcn-vue only.
- The UI follows the design system in [`docs/design.md`](docs/design.md) (semantic tokens, no raw hex).
  A new page also needs an entry in `resources/js/lib/pageLayouts.ts`.
- Verify a library API against its current documentation before you use it; do not rely on memory.

## Safety rules

- **This repository is public.** Never write real hostnames, IP addresses, Discord ids, tokens, keys or
  e-mail addresses into a file, a commit or a pull request. Use placeholders (`lan.example`). Run
  `scripts/ops/check-public-safe.sh` before you push documentation or infrastructure changes.
- **Secrets go into `.env` on the target machine, typed or generated by the human or by you on that machine.**
  Do not print them, paste them into chat, or send them to any service.
- `.env.testing` is committed on purpose (it only encrypts throwaway test data); `.env` is never committed.
- Destructive operations need the human's explicit yes first: `docker compose down -v` (deletes the
  database and uploads), dropping a database, `git push --force`, anything that touches a production host.
- Ask rather than guess when a value, a domain or an account is not given.
