Unreal Tournament 2004 is the LAN's baseline arena shooter, and
`resources/recipes/unreal-tournament-2004/` is the reference recipe. It shows the shape every other
recipe follows: **the base game is required, the VR mod is optional, avatars are optional
multi-select content.**

## What the recipe installs

| Part | Role | Required? | Source |
|---|---|---|---|
| UT2004 DVD 1 (or GOG/Steam install) | `iso` | **Yes** | User-supplied disc image on the LAN file host |
| OldUnreal patch 3374 (Windows x64 / Linux x64) | `patch` | **Yes** | LAN file host; upstream releases |
| UT2004VR by jmkokko (MIT) | `mod` | No | LAN file host / upstream release |
| vrm2ut2004 avatar bridge | `tool` | No | Private repo, built on the LAN server |
| VRM avatars | `avatar` | No, multi-select | LAN file host `.vrm` files |

Disc 1 is enough for the full install; Disc 2 only adds maps and bonus content. The patch is not
optional on modern systems: it is the 64-bit build, removes the disc check and is the version
UT2004VR expects.

```yaml
schema: lanomat.recipe/v1
slug: unreal-tournament-2004
title: Unreal Tournament 2004
aliases: ["ut2004", "ut2k4", "ut 2k4", "unreal tournament", "ut 2004"]
version: "3374"
status: published
platforms: [windows, linux]
metadata:
  genre: arena-shooter
  players: "2-32"
  lan_recommended: true
  live_url: https://ut.raute1.org/   # the operator's deployed UT2004VR/VRM instance
  tags: [fps, vr, classic]
requires:
  - role: iso
    label: "UT2004 DVD 1 (or GOG/Steam install)"
    match: ["ut2004*.iso", "ut2004*dvd*.iso", "UT2004*.iso"]
    required: true
    size_bytes: 4500000000
  - role: patch
    label: "OldUnreal UT2004 patch 3374"
    match: ["OldUnreal-UT2004Patch3374-*.zip", "OldUnreal-UT2004Patch3374-*.tar.bz2"]
    required: true
  - role: mod
    label: "UT2004VR (optional SteamVR mod)"
    match: ["UT2004VR-*.zip"]
    required: false
  - role: avatar
    label: "VRM avatars (multi-select from the LAN file host)"
    match: ["*.vrm"]
    required: false
    tags: [avatar, vrm]
```

In the real file the avatar block repeats one entry per catalogue avatar (Ayla, Brutus, Kestrel,
Mako, Sable). Each entry is an example: the installer matches every `.vrm` on the LAN file host and
shows all matches as one multi-select. If none match, the base install still works.

The agent reads the recipe skill, resolves the ISO and patch on the LAN file host, asks about VR and

```bash

  -H "Authorization: Bearer $LANOMAT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"os":"windows","event_slug":"screenshot-demo"}'
```

The response lists the required files, the optional picks (VR, avatars), target paths and estimated
bytes. No bytes move until the agent confirms.

## The steps

1. **Install the base game.** Mount the ISO and run `Setup.exe` (Windows), or run it through
   Wine/Proton on Linux. Install to a short path without spaces, e.g. `C:\Games\UT2004`. Keep the
   disc mounted until the patch is applied.
2. **Apply OldUnreal 3374.** The archive is a drop-in tree (`Help/`, `Sounds/`, `System/`), not an
   installer. Merge it over the target. `System/UT2004.exe` becomes the 64-bit build and
   `System/D3D11Drv.dll` the modern renderer. On Linux extract the tarball and `chmod +x`
   `System/ut2004-bin-amd64` and `System/UT2004`.
3. **Dismount the ISO.** The patch removes the disc check. If the game still asks for the DVD, the
   patch went to the wrong folder.
4. **Optional: UT2004VR.** Unzip the release, run `Install.bat`, let it find the target. Back up an
   existing `System/d3d9.dll` (ReShade/dgVoodoo) first — the mod needs that name. Start SteamVR
   before the `UT2004 VR` shortcut or `System/Play-VR.bat`.
5. **Optional: avatars.** Pick any number from the multi-select. `vrm2ut2004` converts VRM files to
   UT2004 character packages; build it once on the LAN server and copy the generated packages to
   each client.
6. **Verify.** Start the game, confirm the OldUnreal build in the menu, then
   Instant Action → Deathmatch → DM-Rankin with 4 bots. Check video, audio and input.

## Guards and pitfalls

- **The base is required.** A plan with no ISO and no existing install is invalid.
- **The patch is required.** Without it the retail build asks for the disc and UT2004VR refuses to
  start.
- **VR is optional.** Do not block the base install on a headset, SteamVR or a specific GPU.
- **Avatars are optional and multi-select.** Zero avatars is a valid answer. Never invent a download
  URL for a catalogue entry that has none.
- **VR is offline-vs-bots only.** Joining an online server drops back to a flat screen.
- **`d3d9.dll` is the VR bridge.** Antivirus may flag it; the source is the mod repository.
- **Linux needs the 64-bit OpenAL libraries** shipped in the patch archive.
