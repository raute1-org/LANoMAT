**LANoMAT** is the control desk for a LAN party: registration and tickets, seating, tournaments
with live brackets, schedule, catering, voting, LFG, files, gallery, voice and game servers. One
Laravel monolith, one Vue participant app, one Filament admin panel, a beamer surface — plus an MCP
server and a pi agent so a machine can operate the LAN with you.

The design idea is simple: **the app is a quiet control desk, the beamer is the stage.** Amber is
rationed to the primary action and to what is live right now.

## Two apps, one shell

The participant app (Inertia v2 + Vue 3 + Tailwind v4 + shadcn-vue) and the admin panel (Filament
v5 at `/admin`) share the same brand, tokens and navigation grammar. Same logo mark, same mono
data, same amber signal. A change to the shell reaches both in the same pull request.
