**LANoMAT** is the control desk for a LAN party: registration and tickets, seating, tournaments
with live brackets, schedule, catering, voting, LFG, files, gallery, voice and game servers. One
Laravel monolith, one Vue participant app, one Filament admin panel, a beamer surface — and, since
this docs site, an MCP server and a native agent so a machine can operate the LAN with you.

The design idea is simple: **the app is a quiet control desk, the beamer is the stage.** Amber is
rationed to the primary action and to what is live right now.

## Two apps, one shell

The participant app (Inertia v2 + Vue 3 + Tailwind v4 + shadcn-vue) and the admin panel (Filament
v5 at `/admin`) share the same brand, tokens and navigation grammar. Same logo mark, same mono
data, same amber signal. A change to the shell reaches both in the same pull request.

## A first look

| Dark | Light |
|---|---|
| ![Guest landing of LANoMAT with the mark and the Discord login, dark](/screens/home-dark.png) | ![Guest landing of LANoMAT with the mark and the Discord login, light](/screens/home-light.png) |
| `HOME · DARK` — the login gate, mark and Discord login | `HOME · LIGHT` — same page, paper tokens |

The guest landing is only a login gate: the mark, the wordmark, one line of tagline and hint, and
one primary action, **Mit Discord anmelden**. Once signed in, the participant home answers one
question — *what is next for me?* — and nothing else.

| Dark | Light |
|---|---|
| ![Public event page with lifecycle status, spots left and arrival info, dark](/screens/event-page-dark.png) | ![Public event page with lifecycle status, spots left and arrival info, light](/screens/event-page-light.png) |
| `EVENT · DARK` — lifecycle status, spots, arrival info | `EVENT · LIGHT` — same state, same numbers |

The event page is the aggregate root made visible: registration, seating, tournaments, schedule,
catering and votes all hang off it. The page switches with the lifecycle — `announced` shows the
date, `registration` the primary "Jetzt anmelden", `live` keeps walk-in registration open while
spots remain.

| Dark | Light |
|---|---|
| ![Games library listing every published recipe with LAN availability, dark](/screens/games-dark.png) | ![Games library listing every published recipe with LAN availability, light](/screens/games-light.png) |
| `GAMES · DARK` — published recipes, LAN dot, tournaments | `GAMES · LIGHT` |

The games library and the seating grid are where people spend the evening: every published recipe,
what is on the LAN tonight, and the one-click round into a server. Screenshots in these docs come
from the app's own screenshot set and are shown as light/dark pairs. The beamer (`/screen/{event}`)
is the loud counterpart: large type, no chrome.
